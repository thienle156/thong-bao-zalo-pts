# Thông báo Zalo PTS

App gửi thông báo khoản phải thu cho khách qua Zalo. Nạp file Excel DCRS, duyệt danh sách khách,
gửi lời chào kèm ảnh bảng khoản vay, rồi xuất báo cáo các khách chưa nhận được tin.
Dữ liệu khách chỉ nằm trên máy của người dùng.

## Tải về (bản mới nhất)

- **Mac chip Apple (M1 trở lên):**
  [Thong-bao-Zalo-PTS_mac-arm64.dmg](https://github.com/thienle156/thong-bao-zalo-pts/releases/latest/download/Thong-bao-Zalo-PTS_mac-arm64.dmg)
- **Windows 10/11 (64-bit):**
  [Thong-bao-Zalo-PTS_windows-x64-setup.exe](https://github.com/thienle156/thong-bao-zalo-pts/releases/latest/download/Thong-bao-Zalo-PTS_windows-x64-setup.exe)

Các bản trước: [Releases](https://github.com/thienle156/thong-bao-zalo-pts/releases)

## Cài trên Mac

1. Mở file `.dmg` rồi kéo **Thông báo Zalo PTS** vào thư mục Applications.
   Nếu app cũ đang mở thì thoát app trước, khi được hỏi thì chọn "Thay thế".
2. App chưa được Apple xác thực. Nếu lần đầu mở mà macOS báo không mở được:
   vào **System Settings → Privacy & Security**, kéo xuống dưới và bấm **Open Anyway**.

## Cài trên Windows

1. Chạy file `setup.exe`.
2. App chưa được ký số. Nếu hiện "Windows protected your PC" thì bấm **More info → Run anyway**.

## Lưu ý

- App gửi bằng nick Zalo cá nhân. Đăng nhập bằng cách quét mã QR ngay trong app.
- Trong lúc app đang mở, không mở nick đó trên Zalo PC hay Zalo Web, vì hai nơi sẽ đá phiên của nhau.
- Cài bản mới không làm mất file đã nạp, kết quả đã gửi hay phiên đăng nhập Zalo.
